## Installation

To install this template in Kimai:

1. Copy the `detailed-timesheet.pdf.twig` file to your Kimai installation directory
2. Place it in: `<kimai-root>/var/export/detailed-timesheet.pdf.twig`
3. The template will now be available when exporting timesheets from Kimai

## Usage

1. In Kimai, navigate to the timesheet export section
2. Select the "detailed-timesheet" template from the available templates
3. Configure your export settings (date range, filters, etc.)
4. Export to generate a PDF report in Toggl's detailed report style

## About

This template provides a familiar Toggl-style layout for users who are transitioning from Toggl to Kimai or who prefer Toggl's detailed report format.
